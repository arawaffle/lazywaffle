# LazyWaffle

바탕화면을 대신하는 Windows 위젯 앱입니다. 캘린더 · 체크리스트 · 메모 · 뽀모도로 · D-DAY · 오늘의 일정 전광판 · 하루 타임테이블 · 용돈기입장 · 바로가기를 바탕화면 아이콘 아래에 펼쳐 둡니다.

## 설치 · 실행 (v1.2.0)

| 파일 | 설명 | 데이터 위치 |
| --- | --- | --- |
| `LazyWaffle-1.2.0-setup.exe` | **설치형**. 설치 폴더를 고를 수 있고 바탕화면 · 시작 메뉴 바로가기를 만듭니다. **자동 업데이트**. 제거는 Windows 설정 › 앱에서 | `%APPDATA%\LazyWaffle\data` (제거·업데이트해도 남음) |
| `LazyWaffle-1.2.0-win.zip` | **포터블(압축)**. 풀고 `LazyWaffle.exe` 실행. 시작이 가장 빠름 | 압축을 푼 폴더의 `data\` |
| `LazyWaffle-1.2.0-portable.exe` | **포터블(단일 파일)**. 실행할 때마다 임시 폴더에 풀린 뒤 시작해서 조금 느림 | exe 옆 `LazyWaffle-data\` |

- 처음 실행하면 예시 일정 · 할 일이 들어 있습니다(설정 › 일반·백업 › 모든 데이터 초기화로 비우기).
- 컴퓨터를 켜면 자동 실행됩니다. 설정 › 일반·백업 또는 트레이 메뉴에서 끌 수 있습니다.
- 예전 이름(DeskCalendar)으로 쓰던 데이터는 처음 실행할 때 자동으로 복사해 옵니다(원본 폴더는 그대로 남음). 예전 DeskCalendar 백업 파일도 불러올 수 있습니다.
- 포터블에서 설치형으로 옮길 때는 설정 › 일반·백업의 **백업 내보내기 → 불러오기**를 쓰세요.

### 자동 업데이트 (설치형)

- 시작하고 30초 뒤, 그 뒤로 6시간마다 [GitHub Releases](https://github.com/arawaffle/lazywaffle/releases)에서 새 버전을 확인하고 있으면 조용히 받아 둡니다.
- 다 받으면 알림이 뜹니다. 트레이 메뉴 또는 설정 › 일반·백업 › 업데이트의 **다시 시작해 업데이트**로 바로 적용하고, 그냥 두면 다음에 앱을 끌 때 설치됩니다.
- 데이터 · 자동 실행 설정은 그대로 유지됩니다. 포터블(zip · 단일 exe)은 자동 업데이트가 없으니 새 파일을 받아 바꿔 주세요.
- v1.1.0 이하에는 업데이트 기능이 없어서 v1.2.0 은 한 번 직접 설치해야 합니다.

## 바탕화면 모드

- 창이 바탕화면 아이콘 **아래**(배경화면 레이어)에 붙고, 다른 프로그램은 늘 그 위에 뜹니다.
- 앱 위의 클릭 · 휠 · 끌기는 앱이 받고, 바탕화면 **아이콘 위**의 클릭은 그대로 탐색기로 갑니다.
- 글자를 입력할 때(팝업 · 메모 · 설정)는 **편집 모드**로 잠시 앞으로 올라옵니다. 위쪽에 `편집 모드` 배지가 보이고, 팝업을 닫거나 `Esc` · 다른 창을 누르면 다시 아이콘 아래로 돌아갑니다.
- `Ctrl+Alt+D`: 편집 모드 ↔ 바탕화면 전환.
- **작업표시줄 버튼**: 누르면 편집 모드, 다시 누르면 바탕화면. 우클릭 메뉴에 `편집 모드로 열기 · 화면 설정 · LazyWaffle 종료`, `창 닫기`도 종료입니다.
- **트레이 아이콘**: 편집 모드 · 화면 설정 · 바탕화면 모드 켜고 끄기 · 자동 실행 · 데이터 폴더 열기 · 종료.
- exe 를 한 번 더 실행하면 새로 뜨지 않고 실행 중인 앱을 앞으로 불러옵니다.

## 위젯

**캘린더**
- 일정 유형: 단기 · 장기(여러 날) · 반복(매일 · 매주 · 격주 · 매월 · 매년, 요일 · 종료일) · 기념일(매년).
- 날짜 숫자를 누르면 새 일정, 빈 칸을 끌면 기간을 골라 장기 일정 등록. 월 숫자를 누르면 월 선택, 월간 · 주간 보기 전환.
- 일정을 끌어 다른 날로 이동, `Ctrl` 을 누른 채 놓으면 복사(반복 일정은 그 날짜 하루만). 일정에 마우스를 올리면 이동 · 확인 · 수정 · 복사 · 삭제 버튼.
- 반복 일정은 ‘이 날짜만’ 수정 · 삭제할 수 있습니다(삭제 기본값은 누른 날짜 하루).
- 카테고리(색 · 순서 · 표시 여부), 일정별 색(직접 고른 색은 `+` 로 저장), D-day 표시.
- 일정이 많아 접힌 날의 `+N` 에 마우스를 올리면 그날 일정을 미리 봅니다.
- 한국 공휴일(음력 · 대체공휴일, 2000~2050년) 표시.
- **전체일정관리**: 검색 · 기간 · 카테고리 · 유형으로 거르고, 여러 일정을 골라 카테고리 · D-day · 색을 바꾸거나 한꺼번에 삭제.
- **날짜 칸 이미지**: 일정 등록 창의 ‘칸 이미지’ 탭에서 이미지를 넣고 크롭합니다. 맞춤(채우기 · 전체 보기) · 칸 안 크기 · 위치 · 글자색(자동/직접).

**체크리스트** — 매일 할 일 → 오늘 → 이후(완료 목표일 순). 하위 체크리스트, 진도 도트(2~10칸, 다 채우면 완료), 더블클릭 수정, 끌기나 `Alt+↑/↓` 로 순서 변경, 완료 · 월별 보기.

**메모** — 서식 에디터(굵게 · 기울임 · 밑줄 · 취소선 · 제목 · 목록 · 인용 · 정렬 · 이미지). 이미지는 버튼 · 붙여넣기 · 끌어놓기로 넣고 눌러서 크기를 바꿉니다(긴 변 1600px 로 줄여 `data\assets` 에 저장). ★ 즐겨찾기한 메모는 첫 화면에 슬라이드로 보입니다. `Ctrl+S` 저장.

**뽀모도로** — 집중 · 짧은 휴식 · 긴 휴식, 시간 · 긴 휴식 주기 설정, 자동 시작, 끝나면 알림과 탁상시계 알람 소리.

**D-DAY** — 캘린더에서 ‘D-day 위젯에 표시’를 켠 일정. 끌기나 `Alt+방향키` 로 순서 변경, 팔레트 버튼으로 이름 · 날짜 옆 아이콘(도트 · 라인 · 채움 × 하트 · 별 등 8가지, 위아래 색 따로). ‘남은 날 D-n’ 은 D-DAY 당일까지 보이고 다음 날부터 위젯에서 빠집니다(일정은 그대로). 칸을 넘치면 전광판처럼 흘러갑니다. 나열 방향과 흐르는 속도는 설정 › 레이아웃 › D-DAY 정렬.

**오늘의 일정 전광판** — 오늘 일정이 흘러갑니다(밤 11시부터는 내일 일정). 마우스를 올리거나 화면이 가려지면 멈춥니다. 속도는 설정 › 일반·백업.

**하루 타임테이블** — 일과 + 오늘의 시간 일정을 가로 막대 또는 원형으로. 연필 버튼에서 **매일일과** 또는 **분할일과**(평일 · 주말 등 요일 묶음마다 따로)를 편집합니다.

**용돈기입장** — 설정 › 레이아웃에서 켭니다(빈 자리가 없으면 다른 위젯을 줄이거나 끄세요). 지출 · 수입 · 저축, 결제 수단(카드 · 체크 · 현금/페이), 한 날짜에 여러 줄 한 번에 추가, 달별 합계와 수단별 지출(눌러서 거르기), 연간 합계. 하루 합계(수입 − 지출, 저축 제외)를 캘린더 날짜 칸에 표시합니다(위젯의 달력 버튼 또는 설정에서 끄기).

**스티커 · 바로가기** — 오른쪽 위 스티커 버튼으로 편집: 이미지 스티커를 끌어 이동 · 모서리로 크기 · 손잡이로 회전 · 좌우 반전, 링크를 넣으면 눌렀을 때 웹사이트를 엽니다. 바로가기는 설정 › 스티커·바로가기에서 등록하고, 리스트형(위젯) 또는 자유형(화면 어디에나, 끌어서 이동)으로 둡니다.

삭제 · 이동 뒤 6초 동안 알림의 **되돌리기**로 되돌릴 수 있습니다.

## 화면 설정 (오른쪽 위 톱니)

설정 창은 머리를 끌어 옮기고(더블클릭하면 제자리), 눈 버튼으로 접어 뒤 화면을 볼 수 있습니다.

- **배경**: 배너 · 콘텐츠 배경을 이미지 / 단색 / 메시 그라데이션으로. 이미지는 크롭 · 위치 편집, 배경 이미지 흐림(0~40px), 이미지에서 팔레트를 뽑아 메시 만들기. 배너 · 배경 · 스티커를 **테마**로 저장해 두고 다시 적용.
- **레이아웃**: 배너 위치(왼쪽 · 오른쪽 · 위 · 아래 · 숨김)와 크기(미리보기의 경계선을 끌기), 12×20 격자에서 위젯 끌어 이동 · 가장자리로 크기 조절 · 다른 위젯 위에 놓으면 자리 교체, 위젯 켜고 끄기. 배너가 위 · 아래일 때의 배치는 따로 기억합니다.
- **스티커·바로가기**: 스티커 추가 · 링크, 바로가기 등록 · 순서 · 배치 방식.
- **일반·백업**: 라이트 / 다크 테마, 한 주의 시작, 공휴일 · 용돈 합계 표시, 전광판 속도, 바탕화면 모드, 자동 실행, 모니터 선택, 백업 · 캐시 정리 · 초기화.

배경 위 글자색은 배경의 대표색을 보고 흰색/검정 중 대비가 큰 쪽으로 바뀌고(WCAG 4.5:1 이상), 이미지 · 메시 배경에서는 위젯이 글래스 패널이 됩니다.

## 데이터와 백업

- 모든 데이터는 이 컴퓨터에만 저장됩니다(`state.json` + `assets\`). 하루 한 번 `backups\` 에 자동 백업(최근 14개).
- 배너 · 배경 · 스티커 · 바로가기 이미지는 복사하지 않고 원본 파일을 참조합니다. 원본을 옮기거나 지우면 다시 골라야 합니다. 메모 · 날짜 칸 이미지는 줄여서 `assets\` 에 복사합니다.
- **백업 내보내기**는 참조한 원본 이미지까지 담은 JSON 한 파일을 만듭니다. 다른 PC 에서 불러오면 없는 원본은 `assets\` 로 복원됩니다.
- 고른 모니터는 id 와 위치 · 크기로 기억해, 재부팅 후 모니터 번호가 바뀌어도 같은 모니터에 뜹니다.

## 메모리

- 프로세스는 3개(메인 · GPU · 화면)만 씁니다. 작업표시줄 버튼은 웹 화면 없는 창에 미리보기 이미지만 띄우고, 네트워크 서비스는 메인 프로세스 안에서 돌립니다.
- 앱을 쓰지 않은 지 1분이 지나면(이후 계속 쓰지 않으면 10분마다) 놀고 있는 메모리 페이지를 Windows 에 돌려줍니다. 작업 관리자의 메모리 수치가 크게 줄고, 다시 쓰는 부분은 그때 곧바로 올라옵니다.

## 개발

```bash
npm install
npm run vendor      # Preact · htm · 폰트를 renderer/ 로 복사 (처음 한 번)
npm run dev         # 개발 실행 (데이터: .devdata/, 자동 실행 등록 안 함, F12 개발자 도구)
npm run web         # 브라우저에서 UI 만 확인 (http://localhost:5178, localStorage 저장)
```

| 빌드 | 결과 (`release/`) |
| --- | --- |
| `npm run dist` | 설치형 · 포터블 exe · zip 모두 |
| `npm run build:installer` | `LazyWaffle-<버전>-setup.exe` |
| `npm run build:portable` | `LazyWaffle-<버전>-portable.exe`, `LazyWaffle-<버전>-win.zip` |
| `npm run build` | `win-unpacked/` 폴더만 |
| `npm run release` | `dist` 와 같은 파일을 만들고 GitHub Releases 에 초안으로 올림 (`GH_TOKEN` 필요) |

### 새 버전 배포 (자동 업데이트)

1. `package.json` 의 `version` 을 올립니다 (예: `1.2.0` → `1.3.0`). 같거나 낮은 버전은 업데이트로 인식되지 않습니다.
2. 다음 중 하나로 올립니다.
   - **직접**: `npm run dist` 후 [Releases](https://github.com/arawaffle/lazywaffle/releases) › Draft a new release › 태그 `v1.3.0` 으로 만들고 `release/` 의 `LazyWaffle-1.3.0-setup.exe`, `LazyWaffle-1.3.0-setup.exe.blockmap`, **`latest.yml`** 세 파일을 반드시 함께 첨부(포터블 · zip 은 선택) → Publish.
   - **자동**: `repo` 권한 토큰을 `GH_TOKEN` 환경 변수에 넣고 `npm run release` → 만들어진 초안을 Releases 에서 Publish.
3. 초안(Draft) · 사전 배포(Pre-release)는 업데이트 대상이 아닙니다. Publish 해야 설치된 앱이 받아 갑니다.
4. 설치된 앱은 **로그인 없이** Releases 를 읽으므로 저장소가 **공개**여야 합니다. 비공개 저장소면 확인할 때마다 404 오류가 납니다(로그에만 남고 앱 동작에는 영향 없음).
5. `release/builder-debug.yml` 은 빌드 기록이라 올리지 않습니다 (PC 경로가 들어 있음).

- 공휴일 표 갱신: `npm run holidays` (임시공휴일 · 선거일은 `scripts/make-holidays.js` 의 `EXTRA` 에 추가).
- 앱 아이콘은 `build/icon.png`(256×256)를 교체하면 됩니다 · 작업표시줄 미리보기 이미지 다시 만들기: `npm run taskbar-preview`.
- 제3자 라이선스 고지 `THIRD_PARTY_NOTICES.txt` 는 빌드할 때마다 `npm run notices` 로 다시 만들어지고, 설치 폴더(exe 옆)에 함께 들어갑니다. 의존성 · 폰트를 추가하면 `scripts/make-notices.js` 의 목록도 확인하세요.

```
electron/   main.js(창 · 트레이 · IPC · app:// 프로토콜), win32.js(바탕화면 임베딩 Win32 API, koffi), storage.js(파일 저장 · 백업), updater.js(설치형 자동 업데이트)
renderer/   index.html, css/, js/(Preact + htm, 빌드 없음), fonts/, vendor/
scripts/    vendor.js, make-taskbar-preview.js, make-holidays.js, make-notices.js, serve.js
build/      icon.png, taskbar-preview(@2x).png(작업표시줄 미리보기), installer.nsh(제거 시 자동 실행 등록 정리)
```
